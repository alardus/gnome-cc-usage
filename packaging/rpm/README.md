# Building an RPM for `cc-usage`

This directory has everything needed to produce a Fedora RPM:

- `cc-usage.spec` — the package spec (uses `pyproject-rpm-macros`).
- `Makefile` — convenience targets for tarball / SRPM / RPM.

## One-time setup

```bash
sudo dnf install rpm-build rpmlint pyproject-rpm-macros desktop-file-utils
```

## Build a binary RPM locally

From the repo root:

```bash
make -C packaging/rpm rpm
```

Outputs land under `packaging/rpm/build/`:

- `build/RPMS/noarch/cc-usage-0.1.1-1.fc44.noarch.rpm` — install with `sudo dnf install ./<path>`
- `build/SRPMS/cc-usage-0.1.1-1.fc44.src.rpm` — feed to COPR
- `build/SOURCES/cc-usage-0.1.1.tar.gz` — clean source tarball (from `git archive HEAD`)

The `%check` section runs the test suite during the build, so a build failure
catches broken tests too.

## Submit to COPR

```bash
make -C packaging/rpm srpm
copr-cli build <your-copr-project> packaging/rpm/build/SRPMS/cc-usage-*.src.rpm
```

Once published, end users install with:

```bash
sudo dnf copr enable <your-copr-project>
sudo dnf install cc-usage
```

## What the RPM ships

| Path | Contents |
|---|---|
| `/usr/bin/cc-usage` | entry-point script (auto-generated by pyproject install) |
| `/usr/lib/python3.X/site-packages/cc_usage/` | Python package + bundled resources |
| `/usr/share/applications/cc-usage.desktop` | desktop file for the app launcher |
| `/usr/share/icons/hicolor/scalable/status/cc-usage*-symbolic.svg` | tray + notification icons |

Compared to the `pipx` install path (see top-level `README.md`), the RPM:

- Puts icons on the system icon-theme path so libnotify pop-ups resolve them
  without the manual copy step.
- Registers `cc-usage` with the GNOME app launcher.
- Declares `python3-gobject`, `libayatana-appindicator-gtk3`, `libnotify`, and
  `gnome-keyring` as RPM dependencies, so `dnf` enforces them.

## Bumping the version

1. Update `__version__` in `src/cc_usage/__init__.py`.
2. Update `Version:` in `cc-usage.spec`.
3. Add a `%changelog` entry on top.
4. `make -C packaging/rpm clean rpm`.
